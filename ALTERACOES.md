# Histórico de alterações

## Versão 1.2.0

- inclusão de `docs/requirements-specification.md`;
- formalização de requisitos funcionais, regras de negócio e requisitos não funcionais;
- inclusão de histórias de usuário, critérios de aceitação e caso de uso;
- inclusão de matriz de rastreabilidade;
- registro de lacunas e ambiguidades;
- detalhamento das sugestões de IA aproveitadas, modificadas e descartadas;
- atualização do README para destacar os artefatos da atividade;
- atualização de `docs/architecture.md`;
- atualização de `docs/risk-analysis.md`;
- inclusão de GitHub Actions para executar os testes automaticamente;
- inclusão de teste para rejeição de senha como argumento posicional;
- inclusão de testes para `EOFError` e `KeyboardInterrupt`;
- inclusão de teste para múltiplas violações simultâneas;
- suíte ampliada de 18 para 22 testes;
- versão do projeto atualizada para 1.2.0.

## Versão 1.1.0

- entrada de senha alterada de `input()` para `getpass.getpass()`;
- remoção da senha como argumento da linha de comando;
- remoção da exibição da senha no terminal;
- inclusão de testes de segurança da CLI;
- inclusão de `docs/risk-analysis.md`;
- atualização do README e da documentação de arquitetura;
- atualização da licença com o nome do autor;
- versão do projeto atualizada para 1.1.0.
